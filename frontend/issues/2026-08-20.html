Claude Code Changelog

v2.1.237

Version 2.1.237 of Claude Code includes two changes: a fix for prompt caching when sessions use an LLM gateway or custom base URL, and a new built-in 'Concise' output style option that makes Claude lead with results and skip preamble and narration while maintaining the same thoroughness of work. The Concise style can be selected under Output style in the /config menu.

Why it matters

This is a small but practical update. The prompt caching fix addresses a real issue that would have affected users routing through gateways or custom endpoints, potentially causing unnecessary costs and latency. The 'Concise' output style is a nice quality-of-life addition that acknowledges many developers prefer direct, results-first communication without verbose explanations, which is especially valuable in a coding tool where efficiency matters.
