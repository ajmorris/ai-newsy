Cloudflare plans to issue quantum-safe TLS certificates

Cloudflare announced plans to issue quantum-safe TLS certificates using Merkle Tree Certificates, an approach co-developed with Google that replaces traditional certificate chain signatures with compact Merkle Tree proofs. This addresses the problem that quantum-resistant versions of current X.509 certificates would add roughly 40x the data to TLS handshakes, effectively breaking web performance. By signing only a single 'tree head' representing millions of certificates and using lightweight 'landmark' proofs, handshake data stays around 40 kilobytes. Cloudflare will acquire a trusted certificate root from CA GlobalSign and offer hybrid classic/post-quantum certificates free to all users.
