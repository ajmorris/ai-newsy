Claude Code Changelog

v2.1.246

Version 2.1.246 of Claude Code adds a startup warning for potentially overly-broad Bash allow rules with wildcards before subcommands, an Auto mode tab in the /permissions menu for viewing/editing auto mode classifier rules, and completion timestamps on turn duration lines. It also fixes fullscreen mode blank transcript issues after terminal resizing and other unspecified fixes.

Why it matters

This is a minor incremental update with useful quality-of-life improvements. The wildcard warning for Bash allow rules is a thoughtful security enhancement that helps users avoid accidentally permitting unintended commands. The Auto mode permissions tab adds transparency to how the auto classifier works. The timestamp addition and fullscreen fix are small but welcome polish items. Overall a solid maintenance release.

The chip is designed specifically for AI inference — running trained models to complete tasks or deploy agents.
