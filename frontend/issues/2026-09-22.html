Muse, Meta's extraordinarily privileged AI assistant, has a serious 0-day

Security researcher Patrick Wardle discovered a zero-day vulnerability in Meta's new AI assistant Muse for macOS. The flaw allows any locally installed app or terminal command to access the token authenticating users to their Muse account by exploiting an undocumented setting that changes the transcription endpoint to an attacker-controlled server. Because Muse has extraordinarily broad permissions — including access to WhatsApp, email, calendar, social media, mic, camera, location, and file system — hijacking the agent gives attackers complete control over all of those resources. Wardle demonstrated proof-of-concept attacks including writing malicious files and taking pictures with no user indication. Amazon has also begun blocking Muse from its site. Meta did not respond to questions, despite having published blog posts touting Muse's security design.

Why it matters

This vulnerability illustrates the fundamental tension in deploying highly privileged AI agents: the more useful the agent, the more access it requires, and the more catastrophic a single exploit becomes. Rather than needing to write comprehensive malware, an attacker can simply hijack the agent and leverage its already-granted permissions — a force multiplier that should give the entire industry pause.
