Claude Code Changelog

v2.1.219

Version 2.1.219 of Claude Code introduces Claude Opus 5 as the default Opus model with 1M context and specific pricing, adds a sandbox network strict allowlist setting for denying non-allowlisted hosts without prompting, introduces a DirectoryAdded hook for when new working directories are registered mid-session, and adds MCP server error reporting to the headless stream-json init event for config validation issues.

Why it matters

This is a meaningful release with several practical improvements. The addition of Claude Opus 5 as the default model is the headline feature, offering a large 1M context window. The sandbox network strict allowlist is a welcome security enhancement for controlled environments. The DirectoryAdded hook and MCP server error reporting are useful additions for automation and debugging workflows. Overall, it's a solid incremental update that improves both capability and developer experience.
